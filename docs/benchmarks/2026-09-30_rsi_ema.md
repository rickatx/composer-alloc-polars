# Local RSI/EMA benchmark

Run: `python scripts/benchmark_indicators.py --repeats 3 --output docs/benchmarks/2026-09-30_rsi_ema.json`

This run used Linux 6.6.87.2 WSL2 x86_64, CPython 3.13.9, Polars 1.44.2, and the extracted `composer-alloc-polars` 0.1.4 wheel. The exact Cargo dependency lock is identified by SHA-256 `54a545769e45450b51c0acd6e29be8a69d7446b440fc1aae01dd185de4593fc2`. Peak process RSS, including input frames, was 497,405,952 bytes.

| ---: | ---: | ---: | ---: | ---: |

The [JSON results](2026-09-30_rsi_ema.json) contain all five sizes (100 through 1,000,000), fully valid/prefix/early-poison cases, eager/lazy collection, and one/four expressions. The four-expression case uses slightly shifted input expressions so Polars cannot reuse one identical indicator result. Each case had a warm run followed by three alternating-order timed runs. These are local measurements, not CI thresholds or a cross-version comparison with `polars-talib`.
